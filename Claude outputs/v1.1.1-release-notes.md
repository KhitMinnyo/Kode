## Kode v1.1.1

### Fixed
- **Markdown rendering ("wall of text") bug** — chat responses could fail to render as formatted markdown if the bundled UI libraries (marked, DOMPurify, highlight.js) were missing from the install. The app now self-heals this automatically on install, and shows a clear in-app warning instead of failing silently if it ever happens again.
- **App freezing / Stop button not working** — running a shell command or the test suite could freeze the entire app with no way to recover except force-quitting. `run_command` and `run_tests` now run asynchronously and are properly killable, so the UI stays responsive and Stop actually stops them.
- **Chat messages ballooning with raw JSON** — tool calls (file edits, commands, etc.) always showed their full raw parameters inline, making conversations very long. These are now collapsed by default behind a short, human-readable summary, with the full details available on click.

### Added
- **Live side panel** — a new panel (styled after Claude's own UI) showing real-time plan progress for multi-step tasks and a live view of the active project's file list.
- **In-app update check** — Kode now checks GitHub Releases on startup and shows a banner when a newer version is available to download.
