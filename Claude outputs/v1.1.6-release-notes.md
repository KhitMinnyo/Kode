## Kode v1.1.6

### New
- **Live Preview panel** — view a running development server directly inside Kode with a hardened webview. Console errors can be sent back to the agent for debugging, and screenshots can be captured as attachments for visual feedback.
- **LM Studio provider support** — connect to LM Studio as a first-class local provider using its OpenAI-compatible API.
- **LAN model endpoints** — custom OpenAI-compatible providers now accept scheme-less `IP:port` addresses, making it easier to connect to a model server on another machine on the local network without manually entering `http://` or `/v1`.
- **Persistent task state** — task progress and continuation state are tracked more reliably across long-running agent work.

### Fixed
- **Stalled requests now settle reliably** — stream guards destroy inactive requests with an error instead of leaving promises and Electron IPC calls hanging indefinitely, closing the remaining theoretical `reply was never sent` path.
- **Long-running agent turns are more resilient** — improved iteration, context, verification, and auto-continuation handling helps the agent recover from interrupted or tool-heavy tasks instead of appearing frozen.
- **Provider and renderer reliability** — improved streaming handling, model context limits, preview integration, attachment flows, and UI state updates.

### Internal
- Added shared LM Studio endpoint helpers and expanded stream-guard coverage.
- Added task-state, preview/renderer, provider, prompt, and core regression tests.
- Test suite now passes with the new v1.1.6 coverage; ESLint also passes.
- Bumped version to `1.1.6`.
